# homebrew-tap

Homebrew formulae for [kksat](https://github.com/kksat) projects.

## zals

[zals](https://github.com/kksat/zals) is a Zig Ansible Language Server.

```sh
brew tap kksat/tap
brew install zals
```

The formula is generated and pushed automatically by the
[zals release workflow](https://github.com/kksat/zals/blob/main/.github/workflows/release.yml).
Do not edit `Formula/zals.rb` by hand.
